# Kévin Véronési

Full-stack and AI developer in Toulouse, France.

At [STMS](https://www.stms.fr), an SAP integrator, I'm a Precisely consultant: I build web apps connected to SAP and work on AI projects for the SAP ecosystem. Outside work I build my own projects, mostly in TypeScript, often with Claude Code.

## Projects

- **[Nooki](https://nooki.kevin-dev.com)**: a pixel-art island where friends hang out, with voice chat that fades as you walk away. One Bun server runs Colyseus at 30 ticks per second, Phaser draws the world, and voice goes peer to peer over WebRTC. [How it's built](https://kevin-dev.com/en/projects/nooki)
- **[Mon Garde-Manger](https://github.com/Drosscend/my-kitchen)**: my kitchen inventory and recipe library, with a cooking mode for the phone. An MCP server sits behind its own OAuth server, so an assistant like Claude can read the pantry and add recipes. AdonisJS, React, PostgreSQL. [Live](https://my-kitchen.kevin-dev.com)
- **[kevin-dev.com](https://github.com/Drosscend/kevin-dev.com)**: my site, with portfolio, blog, résumé and an admin area to edit it. AdonisJS 7, Inertia, React with SSR.
- **[CronLab](https://github.com/Drosscend/CronLab)**: a task scheduler for Windows 11, Rust and React on Tauri v2.
- **[LicenseKit](https://github.com/Drosscend/licensekit)**: a CLI to choose an open-source license, understand it and add it to a project. `npx @drosscend/licensekit`
- **[MiniBox](https://github.com/Drosscend/MiniBox)**: my bachelor's thesis, built as a team. A small box that counts bikes and their direction with YOLOv5, without storing images.
- **[CSV to RDF annotation](https://github.com/Drosscend/web-semantique)**: a master's project on the SemTab 2024 tables. It links CSV columns and cells to Wikidata, without a language model.

Some projects are private, like [Vigie](https://kevin-dev.com/en/projects/vigie), my second brain: I tell Claude about my day and it files everything into a journal, tasks and reminders. They're written up on my site.
